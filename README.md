## 功能一覽

- **雙人對弈**：支援 19、13、9 路棋盤、彈性棋鐘、提子、打劫判斷、虛手、悔棋請求及觀戰推演。
- **擺盤研究室**：多人同步研究、主講權交接、多條變化圖、自由擺子與盤面註釋。
- **雲端棋譜庫**：收藏棋譜，支援標準 SGF 匯入、匯出與備份還原。
- **跨裝置識別碼**：使用同一組雲端識別碼，可在不同裝置找回角色資料與棋譜。
- **房間分享**：複製房間連結，邀請朋友直接加入。

## 快速開始

1. 開啟[圍棋大廳](https://cxxlmanself.github.io/weiqi/)。
2. 可先設定暱稱與雲端識別碼。
3. 點選「＋ 建立房間」建立對弈或研究室，或加入大廳中的現有房間。
4. 進入房間後，使用「🔗 分享連結」邀請朋友。

完整操作方式請看 **[網頁版使用說明](https://cxxlmanself.github.io/weiqi/manual.html)**。
