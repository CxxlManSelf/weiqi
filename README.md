# 🏁 雲端圍棋對弈與擺盤研究室 — 使用介紹

這是一個**免下載 App、免繁瑣註冊、手機與電腦打開網頁就能直接下棋與覆盤研究**的線上圍棋平台！只要點開連結、設定好自己的暱稱與專屬識別碼，就能隨時跟棋友連線對弈，或是一起語音覆盤研究。

## ✨ 四大核心特色

### 1. 免下載即開即玩，專屬識別碼跨手機／電腦同步與累積戰績

* **零安裝門檻**：不需要下載任何 App，用手機、平板或電腦瀏覽器點開就能玩。

* **專屬雲端識別碼（跨裝置認領角色、戰績與棋譜）**：點擊右上角「`棋友_XXXX ✎`」，輸入你習慣的代號（或 Gmail 信箱，可選填 PIN 碼保護）並套用，以後無論換手機、換電腦，甚至網頁未來升級改版，只要輸入同一組識別碼，就能**自動找回你的暱稱、建立的房間管理權、雲端保存的所有棋譜，以及個人歷史勝敗戰績**！

* **🏆 勝敗戰績自動累積與即時展示**：每局雙人對弈結束後，系統會自動為雙方識別碼累計「勝次數」與「敗次數」，並在對弈席位與「👥 房內在線成員」清單中即時顯示每位棋友的戰績徽章（例如 `3勝 1敗`）。

* **傳統榧木棋盤與防誤觸設計**：支援 **19 路、13 路、9 路**三種棋盤與清脆落子音效；手機螢幕點擊可先預覽落子位置、按「確認落子」才算數，不怕手滑點錯。

### 2. ⚔️ 雙人對弈室（下棋＋觀戰自由推演）

* **完整圍棋規則**：支援自動提子、打劫判斷、虛手（Pass）、請求悔棋、中盤認輸與一鍵數子點目參考。

* **彈性棋鐘設定**：可選自由時間（無限制），或 1～30 分鐘基本時限搭配多種讀秒（10秒～120秒 × 3次）。

* **觀戰也能自己擺變化**：旁觀棋友在觀戰時，可以隨時前後翻看棋譜，甚至直接在自己畫面上試下「本端變化圖」，完全不會干擾兩位選手的實況對局，點一下就能回到最新戰況。

* **終局輕鬆開新局**：對局結束後可一鍵存譜，房主開啟新棋局時，空出的席位開放所有棋友「先搶先贏」入座！

### 3. 🔬 擺盤研究室（覆盤教學＋語音／註釋時光機）

* **單人主講不混亂**：由一位主講人統一控制盤面（暫時離開大廳也會保留主講權，點擊「放棄擺盤權」才會交棒給下一位），支援多條「變化圖線程」、擺子模式與手數重編號。

* **🎙️ 語音講解與 📝 盤面註釋連動**：主講人可以「按住說話」錄製語音解說，或寫下盤面註釋；其他棋友在聊天室點擊語音或註釋卡片時，**棋盤會自動跳轉到錄製當下的那一手變化圖**，邊聽邊看超直覺！

* **聽眾自由試下**：聽講的棋友也能隨時在自己裝置上前後翻閱手數或建立本端變化圖推演，一鍵即可跟回主講人最新進度。

### 4. ☁️ 雲端棋譜庫（SGF 匯入與收藏）

* 對弈或研究到一半，隨時都能把整局（包含所有變化圖）存入你的專屬雲端棋譜庫、下載 `.sgf` 檔案，或複製 SGF 文字分享給朋友。

* 也能隨時匯入外部的 `.sgf` 棋譜檔，一鍵開啟擺盤研究室進行覆盤。

## 🚀 三步驟快速上手

1. **設定暱稱與專屬識別碼**：進入網頁後，點擊右上角「`棋友_XXXX ✎`」，填入你的暱稱，並設定一組好記的「專屬雲端識別碼」（可選填 PIN 碼保護）按下套用，以後換裝置也不怕資料與戰績不見。

2. **加入或建立房間**：在大廳直接點擊現有房間加入，或按「**＋ 建立房間**」選擇「雙人對弈」或「擺盤研究室」。

3. **一鍵分享邀請朋友**：進房後點擊上方的「**🔗 分享連結**」或「`#房號 📋`」傳給朋友，朋友點開連結就會直接進入你的房間！
