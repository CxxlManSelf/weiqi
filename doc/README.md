## ✨ 四大特色亮點

1. **免下載、免註冊，點開即玩**
   不需要安裝任何 App，也不用綁定繁瑣的帳號密碼，打開網址就能直接在大廳開房或加入對局。
2. **一組「專屬識別碼」跨裝置同步**
   系統會自動配發一組雲端識別碼（也可自訂好記的代號或信箱）。只要在手機或電腦輸入同一組識別碼，就能自動找回您的**暱稱、戰績勝率、房間管理權與雲端棋譜庫**。
3. **一鍵產生房間連結，秒邀好友進房**
   開好房間後點擊頂部的 **「🔗 分享連結」**，把網址傳給 LINE 或社群好友，對方點擊就會直接進入您的房間，不用手動找房號。
4. **大廳醒目約戰與逾時自動清房**
   正在等待對手的房間會自動置頂並醒目標示空席；建立對弈室時還可設定「等待入席時限」（十分鐘、三十分鐘、一小時、一天或無限等待），逾時未滿席將自動刪房，讓大廳隨時保持清爽。

## 🎮 核心功能介紹

### 1. ⚔️ 雙人對弈室（支援快棋與通信慢棋）
* **多種棋盤路數**：支援 **19 路、13 路、9 路** 棋盤，新手入門或正式對局都適合。
* **彈性棋鐘設定**：從無限制自由時間、1～30 分鐘快棋，到 **1 天／1 週一手的通信慢棋** 皆可設定，系統還會自動統計「我的對戰房間」待落子提醒。
* **防手滑確認落子**：手機點擊交叉點會先顯示半透明預覽，確認無誤再落子，不怕螢幕小點錯位置。
* **完整對局工具**：內建提子、打劫判斷、虛手 (Pass)、請求悔棋、數子點目參考，終局自動累計勝敗戰績。
* **觀戰自由推演**：旁觀棋友可在自己的畫面上隨意試下變化圖，完全不會干擾場上兩位棋手，隨時一鍵回到實況。

### 2. 🔬 擺盤研究室（線上教學與覆盤神器）
* **多人同步擺盤與主講權轉移**：適合老師授課或棋友覆盤，主講人可隨時「放棄擺盤權」讓其他棋友接手操作。
* **多線程變化圖 & 自由擺子**：支援建立多個變化圖分支、自由擺放黑白棋子（擺死活題超方便）以及手數重新編號。
* **互動式「盤面註釋」**：主講人送出盤面註釋後，聊天室會自動綁定當下的分支與手數；其他棋友只要點擊註釋卡片上的按鈕，棋盤就會自動跳轉到該手數的盤面！

### 3. ☁️ 雲端棋譜庫（支援標準 SGF）
* 對弈結束或研究完成後，可一鍵將棋譜存入雲端棋譜庫，隨時開啟「擺盤覆盤」。
* 支援標準 `.sgf` 棋譜檔案上傳、貼上文字匯入、下載儲存，以及整包備份還原。

## 🚀 三步驟快速上手

1. **點擊網址進入大廳**：開啟 <https://cxxlmanself.github.io/weiqi/app/index>，點擊右上角可修改棋友暱稱（建議順便記下或自訂您的「專屬雲端識別碼」）。
2. **建立或加入房間**：
   * 點擊 **「＋ 建立房間」**，選擇「雙人對弈」或「擺盤研究室」與棋盤大小。
   * 或直接點擊大廳列表上方醒目的「等待對局」房間立即應戰。
3. **分享連結開戰／研究**：進入房間後點擊頂部的 **「🔗 分享連結」** 傳給朋友即可開始！更多詳細功能說明請參閱 [使用簡介](https://cxxlmanself.github.io/weiqi)。
