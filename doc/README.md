## ⚠️ 重要使用提醒（房間隱藏與保存規則）

在使用平台開房對弈或研究時，請特別留意以下兩項自動管理機制（進行中的慢棋對弈室會完整保留，不會被誤藏或刪除）：

1. **24 小時未活動自動隱藏**：**擺盤研究室**以及**已結束的雙人對弈室**若超過 **24 小時** 沒有任何落子或聊天活動，將會從大廳列表中自動隱藏（仍可透過輸入房號搜尋或原有分享連結重新進入）；尚未結束的對弈室則會持續顯示在大廳中。
2. **已結束的對弈室 15 天未活動自動刪除**：**已對局結束**的雙人對弈室若超過 **15 天** 沒有任何活動，系統將會自動永久刪除該房間。**因此重要的對弈請務必在對局後點擊「💾 儲存棋譜」**，將棋譜存入您的「雲端棋譜庫」或下載 `.sgf` 檔案妥善保存！

## ✨ 為什麼推薦使用？四大特色一次看

1. **點開即玩，不用安裝也不用註冊**
   免下載 App、不用綁定繁瑣帳號密碼，打開網址就能直接在大廳開房或加入對局。

2. **一組「專屬識別碼」跨裝置同步**
   系統會自動配發一組雲端識別碼（也可自訂好記的代號或信箱）。只要在手機或電腦輸入同一組識別碼，就能自動找回您的 **暱稱、勝敗戰績、房間管理權與雲端棋譜庫**。

3. **一鍵複製連結，秒邀好友進房**
   開好房間後點一下頂部的 **「🔗 分享連結」**，把網址傳給 LINE 或社群好友，對方點擊就會直接進入您的房間，不用手動找房號。

4. **大廳醒目約戰，等待清爽不雜亂**
   正在等待對手的房間會自動置頂並醒目標示空席；開房時還可設定「等待入席時限」（十分鐘、三十分鐘、一小時、一天或無限等待），逾時未滿席將自動清房。

## 🎮 核心功能介紹

### 1. ⚔️ 雙人對弈室（支援快棋與通信慢棋）
* **三種棋盤路數**：支援 **19 路、13 路、9 路** 棋盤，新手入門或正式對局都適合。
* **彈性棋鐘規則**：從無限制自由時間、1～30 分鐘快棋，到 **1 天／1 週一手的通信慢棋** 皆可設定，系統還會自動提醒「我的對戰房間」輪到您落子。
* **防手滑確認落子**：手機點擊交叉點會先顯示半透明預覽，確認無誤再按「確認落子」，不怕螢幕小點錯位置。
* **完整規則與觀戰推演**：內建提子、打劫判斷、虛手 (Pass)、請求悔棋與數子點目；旁觀棋友還能在自己畫面上自由試下變化圖，完全不干擾場上棋手。

### 2. 🔬 擺盤研究室（線上教學與覆盤神器）
* **多人同步擺盤與主講權移交**：適合老師授課或棋友共同研究，主講人可隨時「放棄擺盤權」讓其他棋友接手操作。
* **多線程變化圖 & 自由擺子**：支援建立多個變化圖分支、自由擺放黑白棋子（擺死活題超方便）以及手數重新編號。
* **互動式「盤面註釋」**：主講人送出盤面註釋後，聊天室會自動綁定當下的分支與手數；其他棋友只要點擊註釋卡片上的按鈕，棋盤就會自動跳轉到該手數的盤面！

### 3. ☁️ 雲端棋譜庫（支援標準 SGF）
* 對弈結束或研究完成後，可一鍵將棋譜存入雲端棋譜庫，隨時開啟「擺盤覆盤」。
* 支援標準 `.sgf` 檔案上傳、貼上文字匯入、下載儲存，以及整包備份還原。

## 🚀 三步驟快速上手

1. **開啟網站進入大廳**：前往 <https://cxxlmanself.github.io/weiqi/>，點擊右上角可修改您的暱稱（建議順便記下或自訂「專屬雲端識別碼」）。
2. **建立或加入房間**：
   * 點擊 **「＋ 建立房間」**，選擇「雙人對弈」或「擺盤研究室」與棋盤路數。
   * 或直接點擊大廳上方醒目的「等待對局」房間立即應戰。
3. **分享連結並保存棋譜**：進入房間後點擊頂部的 **「🔗 分享連結」** 傳給好友即可開戰；對弈完成後別忘了點擊 **「💾 儲存棋譜」** 永久收藏！更多細節可參考 [完整使用簡介](https://cxxlmanself.github.io/weiqi/doc)。
